# MT5 XAUUSD Analyzer — сигналы по стратегии H1/H4 (без автоторговли)

Модульный анализатор для MetaTrader5: тренд-фильтр EMA(50) на H4, вход на
откате к EMA(21) на H1 с выходом RSI(14) из зоны 40–50 и подтверждающей
свечой. SL = 1.5×ATR(14), TP = RR 1:2. Только анализ и сигналы — ордера не
выставляются.

## Структура

| Файл | Назначение |
|---|---|
| `config.json` | все параметры стратегии (периоды, зоны RSI, часы, новости, Telegram) |
| `data.py` | данные: MetaTrader5 (Windows) или CSV (для разработки/бэктеста где угодно) |
| `strategy.py` | индикаторы, фильтры (сессия 10:00–20:00 UTC+5, новости ±30 мин), сигнал |
| `backtest.py` | walk-forward бэктест: win rate, profit factor, max drawdown, средний R |
| `notifier.py` | журнал сигналов в CSV + уведомления в Telegram |
| `main.py` | CLI: `run` (живой цикл) и `backtest` |

## Запуск (Windows + терминал MT5)

```bat
pip install MetaTrader5
python main.py backtest --bars 5000   :: бэктест на истории MT5
python main.py run                    :: живой анализ, сигнал на закрытии H1
```

Терминал MT5 должен быть установлен и залогинен в счёт брокера с символом
XAUUSD (если символ называется иначе, напр. XAUUSD.m — поменяйте в config).

## Бэктест без MT5 (любая ОС)

```bash
python3 main.py backtest --csv xauusd_h1.csv
```

CSV-колонки: `time,open,high,low,close` (time — epoch-секунды UTC или
`YYYY-MM-DD HH:MM`). H4 автоматически собирается из H1.

## Telegram-уведомления

В `config.json` заполните `telegram_token` (от @BotFather) и
`telegram_chat_id` (узнать у @userinfobot). Пусто — сигналы только в
консоль и CSV.

## Правила стратегии (лонг; шорт зеркально)

1. H4: закрытие выше EMA(50) → только лонги
2. H1: за последние 3 бара цена касалась EMA(21)
3. RSI(14): предыдущий бар в зоне 40–50, текущий выше 50
4. Подтверждение: бычья свеча с закрытием выше EMA(21)
5. SL 1.5×ATR(14), TP = 2×SL
6. Сигналы только 10:00–20:00 UTC+5; не ближе ±30 мин к новостям из
   календаря (`news_events_utc` — поддерживайте список актуальным!);
   максимум 2 сигнала в день (лимит переживает перезапуск — считается по CSV)

## Результат проверки на реальных данных

Бэктест на 5000 часовых баров золота (~7 месяцев, данные Binance PAXG):
97 сигналов, 67 сделок, win rate 34.3%, profit factor 1.05, +2.0R,
просадка 10.6%. То есть стратегия в этом виде — **около нуля**: правила
рабочие, но без оптимизации параметров прибыли не дают. Параметры вынесены
в config именно для этого — меняйте зоны RSI, периоды EMA и окно сессии и
сравнивайте метрики. Не financial advice.
